This project presents the design and implementation of a custom flight controller that leverages a dual-processor architecture to achieve high-performance drone stabilization and advanced telemetry logging. The objective of this system is to integrate a high-performance microcontroller with a dedicated wireless transceiver and modem chip to create a modular balance between real-time hardware reliability and long-range data processing. The methodology utilizes the microcontroller as a low-level processing unit to manage time-critical tasks, such as sensor fusion and PID control loops, ensuring immediate flight stability. Simultaneously, the integrated modem and transceiver act as the primary communication bridge, providing high-bandwidth telemetry logging and a robust data link to a ground-based monitoring station. As an anticipated result, this integration allows for a more detailed analysis of flight dynamics and an expanded operational range by utilizing specialized hardware for secure data transmission and remote monitoring. Ultimately, this research concludes that interfacing dedicated communication chips with high-speed microcontrollers provides a versatile and efficient alternative to traditional standalone flight controllers, centralizing complex telemetry and long-range connectivity within a single, integrated custom hardware architecture.
