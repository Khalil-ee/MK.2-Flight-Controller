This project presents the design and implementation of a custom flight controller that leverages a dual-processor architecture to achieve high-performance drone stabilization and advanced telemetry logging. The objective of this system is to integrate a microcontroller with an Android smartphone via a USB-based interface to create a modular balance between real-time hardware reliability and high-level data processing. The methodology involves uses a microcontroller as a low-level processing unit to manage time-critical tasks, such as sensor fusion and PID control loops, ensuring immediate flight stability. Simultaneously, the smartphone acts as the primary computer interface, providing high-level control inputs, comprehensive real-time telemetry logging, and a sophisticated graphical user interface through the USB connection. As an anticipated result, this integration allows for a more detailed analysis of flight dynamics and a streamlined pilot interface by utilizing the smartphone's existing hardware for data storage and display. Ultimately, this research concludes that interfacing mobile computing power with dedicated microcontrollers provides a versatile and efficient alternative to traditional standalone flight controllers, centralizing complex telemetry and user interaction within a single, integrated mobile device.
